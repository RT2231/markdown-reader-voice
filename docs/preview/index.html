    バックグラウンド再生
    ElevenLabsエンジンはMedia Session APIに対応し、画面ロック中でも再生が継続しやすくロック画面操作にも対応します。ブラウザ標準エンジンはOS・ブラウザの制約で一時停止される場合があり、自動再開を試みますが完全な保証はできません。
